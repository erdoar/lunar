# P.L.U.S. — polar lunar solar

Concept design for a 108 m rotating solar mast at a lunar pole. Live site: https://lunar.nulytica.com

- `DESIGN.md` — the design document (rev 33)
- `*.svg` diagrams, redrawn by the `make_*_svg.py` scripts
- `*_check.py` — sizing checks
- `render/` — parametric Blender model; `renders/` holds its output
- `site/` — the website: `python3 site/build.py` writes `site/dist/`, which is deployed to the Netlify project `plus-lunar`
